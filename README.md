# Hällingsjö Entreprenad – webbplats

Statisk webbplats (HTML/CSS/JS, inga beroenden). Öppna `index.html` direkt eller lägg upp mappen på valfri webbhotell (Netlify, GitHub Pages, Loopia m.fl.).

## Att göra innan publicering

- **Bekräfta tjänsterna** med företaget. Listan under *Verksamhet* bygger på verksamhetsbeskrivningen i företagsregistret.
- **Offertformuläret**: sätt `FORM_ENDPOINT` i `script.js` (t.ex. en Formspree-adress) så kommer förfrågningar som e-post. Utan den öppnar formuläret ett färdigskrivet sms till 072-573 85 61.
- **Bilder**: bilderna i `bilder/` är stockfoton från Pexels (fri licens, ingen attribuering krävs). Byt gärna mot egna projektbilder med samma filnamn när de finns.
